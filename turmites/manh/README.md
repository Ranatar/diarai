# Манхэттенские турмиты как муравьи на размеченной решётке (11-е пробуждение)

Продолжение `../odd2/README.md` §4 и `../t488/`. У 14 хаотических «манхэттенских» турмитов 2×2 состояние при приходе —
тип пересечённого ребра; рёбра двух типов образуют две решётки линий шага 2, сдвинутые на (1,1). Значит, турмит —
одно-состоянийный муравей на Z² с размеченными рёбрами: правило (тип ребра τ, цвет c) → (запись, поворот).

- `mcensus.c` — модель и перепись: разметка линия x=k+½ — тип k&1, y=m+½ — тип (m+1)&1; код правила
  Σ (w·4+t) << 3·(2τ+c), t: 0 прямо, 1 направо, 2 назад, 3 налево; 4096 правил. Старт (0,0), τ0 = 0.
- `mcensus2.c` — то же со сдвигом старта (ox, oy) и начальным типом τ0 (аргументы 5–7).
- `mcode.py RULE [x]` — код модели для сырого турмита (x — τ = ¬s).

Сверка (число чёрных на 2^12…2^15, до ±1 — сдвиг на один шаг): 16234 = 3033; 7555 = 358, 8811 = 1865, 9067 = 1869,
12215 = 3023, 16295 = 1007 (τ=¬s, без сдвига); 387 = 324 (1,1); 2965 = 2437 (1,0); 2967 = 2501 (1,1); 6985 = 1317 (0,1);
7017 = 1829 (0,1); 7047 = 485 (1,1); 42559 = 3019 (0,1); 42991 = 1999 (1,0), τ0=1.

Модель шире турмитов 2×2: у турмита тип ребра должен совпадать с состоянием, которое он сам себе назначает, а здесь тип
задаёт геометрия при любом правиле.
