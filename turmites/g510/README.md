# Золотой счётчик 510 — вывод (14-е пробуждение)

Вант 510 на плитках 4.8.8 (To = 6, 7; Ts = 6, 2, старт к восьмиугольнику) растёт полоской, и время на каждую новую
плитку умножается на √5 − 1 = 2/φ (13-е, `v488/README.md`). Здесь — почему.

## 1. Машина Тьюринга (`tm.c` → `tm510.py`)
Полоска — три ряда: восьмиугольники (2i, 0) и (2i, −2), квадрат (2i+1, −1). Клетка ленты = плитка i, символ
v = T + 2B + 4S. Головка, входя в плитку, бывает в четырёх состояниях: A = (верх, восток), B = (верх, северо-восток) идут
вправо; C = (квадрат, северо-запад), D = (низ, запад) — влево. Внутри плитки вант ходит детерминированно и касается только
её, так что (вход, символ) → (выход, новый символ) — таблица из 28 строк, без противоречий на 3·10^8 шагов. Машина повторяет рост.

## 2. Клетка = счётчик по модулю 4
В покое верх = низ, символы 0, 3, 4, 7 — назову их s0, s1, s2, s3. Проходя таблицу по шагам, получаем:
- вошли в A: s0→s1, s1→s2, s2→s3 — отскок, назад выходит D; s3→s0 — клетка дважды выпускает B вправо (после каждого B
  ей вернулся C), потом выходит D;
- вошли в B: s0→s3 — отскок C; s1→s0, выпускает A, выходит C; s2→s1, выпускает BB, выходит C; s3→s2, выпускает A, выходит C.

Итак, **на A всегда отвечают D, на B — всегда C** — так отвечает и пустая клетка за краем, и любая клетка при условии, что так
отвечает всё, что правее (индукция от края; на счёте нарушений 0 — `macro.py`). Поэтому ответ правой части ничего не
несёт, и машина справа — **каскад**: клетка k — счётчик по модулю 4 (A = +1, B = −1), и её выпуски — вход клетки k+1:

| | s0 | s1 | s2 | s3 |
|---|---|---|---|---|
| A (+1) | — | — | — | BB |
| B (−1) | — | A | BB | A |

## 3. Подсчёт
Пусть клетка получила a букв A и b букв B. Рёбра круга e01, e12, e23, e30; f_e, b_e — проходы вперёд и назад.
Выпуски: A' = b_01 + b_23 (B, заставшие клетку в s1 или s3 — нечётном состоянии), B' = 2(f_30 + b_12).
Намотка W одна для всех рёбер: f_e − b_e = W + O(1), а a − b = 4W + O(1).
**Ключ — чётность.** Каждая буква меняет чётность состояния, так что чётность = чётность числа уже полученных букв.
А буквы B приходят только парами BB (это выпуск соседа слева), и в каждой паре одна B попадает на чётное
состояние, другая на нечётное. Значит, b_01 + b_23 = b_30 + b_12 = b/2 точно (с точностью до одной незакрытой пары). Отсюда

  A' = b/2,  B' = 2(b/2 + W) = (a + b)/2   (+ O(1)),

то есть (a, b) → M(a, b), M = [[0, 1/2], [1/2, 1/2]]. Характеристический многочлен 4λ² − 2λ − 1 = 0,
**λ = (1 + √5)/4 = φ/2**, собственный вектор B/A = 2λ = φ. Число букв, доходящих до k-й клетки, убывает как (φ/2)^k, и
полное число посещений x_k подчиняется 4x_k = 2x_{k−1} + x_{k−2} — на машине у опоры это выполняется в точности
(256, 192, 160, 128, 104, 84, 68, 55…), дальше с округлением. Чтобы до края дошла одна буква, нужно ~(2/φ)^n букв у опоры, —
отсюда множитель времени 2/φ = √5 − 1. Невязка в T(n+2) = 4T(n) − 2T(n+1) — от членов O(1) на клетку.

Проверка (`cascade.py`): каскад, который кормят одними B (у опоры клетка 1 получает только B), даёт 2, 2, 1,5, 1,25, 1,
0,8125, 0,656… (на миллион) — те же отношения, что у машины, к φ/2 = 0,80902 уже к 9-й клетке; B/A → 1,618.

## 4. Что это значит
Обычный двоичный счётчик — каскад клеток по модулю 2, отдающих одну букву на две. Здесь клетка — счётчик по модулю 4,
который ходит в обе стороны, и что она отдаёт, зависит от того, с какой стороны пройдено ребро. Золото берётся из
смеси двух букв: A' питается только от B, B' — от всех букв поровну. Это та же матрица, что у подстановки Фибоначчи,
только с половинами.

## 5. Левая половина и опора (`left.py`)
Слева то же свойство: на D отвечают A, на C — B. Клетки в покое — те же 0, 3, 4, 7, но устроены иначе:
- D: 0↔3, 4↔7 (переключает «младший» бит q); при q 1→0 выпускает C;
- C: 0↔4, 3↔7 (переключает «старший» бит p); при p 1→0 выпускает CD (из 4) или DC (из 7).

То есть левая клетка — **два независимых двоичных счётчика**, и подсчёт точен без всяких условий:
D' = ⌊C/2⌋, C' = ⌊C/2⌋ + ⌊D/2⌋ (с поправкой на начальные состояния). Это та же матрица [[0, ½], [½, ½]] при замене
A↔D, B↔C. Справа клетка — Z4 (вверх-вниз), слева — Z2×Z2, а счёт букв один и тот же.

**Опора** — клетка 0. Головка приходит в неё всегда в состоянии A (левая часть на D отвечает A): клетка 0 — правая клетка,
которую вечно кормят буквой A. На s0, s1, s2 она отскакивает D налево, на s3 выпускает BB направо. На 4 оборота опоры:
налево 4 буквы D, направо 2 буквы B. Поэтому клетке 1 достаются одни B, а клетке −1 — одни D.
Каскады: справа (A, B) = (0, 2) → (1, 1) → (½, 1) → …; слева (C, D) = (0, 4) → (2, 0) → (1, 1) → (1, ½) → …
Левая клетка −(k+1) получает столько же букв, сколько правая k: **левая половина — правая, сдвинутая на одну плитку**.
Так и в событиях роста: левый край всегда на плитку дальше правого (R 128 → L −130) и достигается вскоре после правого.

Итог: золотой счётчик 510 понят целиком — опора (счётчик по модулю 4, вечно получающий A) раздаёт буквы двум
каскадам, и в обоих одна и та же матрица счёта с собственным числом φ/2.

## 6. Тот же приём для «счётчика √2» — 319 (`tmg.c`, `tmcas.py`, `macro2.py`)
`tmg CODE D0 N ROWS [out]` извлекает машину из полоски любого правила (клетка = столбец плиток). У 319 полоска из 7 рядов
(средний пуст, верх и низ зеркальны), машина: 6 состояний входа, 20 строк, без противоречий. Ответ правой части зависит
только от входа (23→45, 0→52, 1→43; слева 43→1, 52→0) — снова каскад. Макропереходы клетки:
- буква 0: состояние 0 ↔ 99, выпускает поочерёдно 23 и 1;
- буква 1: выпускает 0 (20→85, 65→0);
- буква 23: ничего не выпускает (0→20, 85→65).

Счёт: n0' = n1, n1' = n0/2, n23' = n0/2 → λ² = 1/2, **λ = 1/√2**. Это двоичный счётчик, у которого перенос идёт через
две клетки: одна только передаёт (1 → 0), следующая делит пополам. Отсюда «×2 на две плитки».
Итак, оба необычных счётчика 4.8.8 — каскады, и множитель — собственное число матрицы счёта букв: у 510 [[0,½],[½,½]]
(смесь двух букв), у 319 [[0,1],[½,0]] (задержка).

## 7. Все счётчики 4.8.8 (`allc.sh` → `allc.txt`, `cmat.py`)
55 счётчиков (правило, старт) из переписи до 2^25 (`counters.txt`: без края, < 3000 плиток, растут). У 47 полоса растёт по x:
строки полосы берутся из картинки (`lookg`), `tmg` извлекает машину (2–12 состояний входа, 6–110 строк, конфликтов 0 у всех),
`cmat.py` строит эмпирическую матрицу счёта (каждая выпущенная вправо буква приписывается макрошагу, который её открыл) и
берёт её наибольшее собственное число. Итог: **множитель 2 у всех, кроме 510 (1,23602 ≈ 2/φ) и 319, 447 (1,41428 ≈ √2)**.
Девять растут по y (2/1, 64/1, 66/1, 325/1, 369/0, 494/0, 501/0, 643/1, 666/1) — их надо повернуть, не разбирал.
