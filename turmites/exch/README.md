# Обменщики

Правила «пишет s, новое состояние = ¬c» (20 хаотических классов, `chaos.txt`, + 6958).
В шахматной раскраске c̃ = c⊕(x+y), σ = s⊕t муравей **на каждом шаге меняется жетоном с клеткой**:
кладёт свой σ, забирает c̃ клетки. Жетон покинутой клетки переезжает в следующую — муравей тащит жетоны.
Отсюда сохранение массы (число единиц c̃ в теле − фон + σ = 0). Поворот зависит от (σ, c̃, цвет клетки в шахматке);
только у 16234 — лишь от «равны / различны» (R при равных, L при разных).

`exlab.c` — жетоны с номерами (дом). `exlab RULE MAXLOG` (меняться всегда) / `exlab_d` (-DONLYDIFF=1, только разными):
на 2^k — доля сдвинутых, средний/макс. сдвиг, радиальный сдвиг, msd, t/A; в конце `lab_RULE.pgm` (яркость = сдвиг).

Итоги (9-е пробуждение, `lab24.txt`, `msd25.txt`):
- **кристаллы** — 16234 (сдвиг ≤ 1), 7470, 6990 (≤ 3): msd не растёт, тело — правильная решётка;
- **мешалки** — остальные: msd = q·t/A, q постоянно на 2^15…2^25 (0,27…1,92); 23336 — субдиффузия.
  Каждое посещение — один толчок; жетоны в среднем сносит к центру.

## Как растёт подметальщик 16234 (10-е пробуждение, `sweep/`)

- Рамка — квадрат, растёт на 1 по x и y у одного угла, углы по кругу; t ~ L^3,6 (`sweep/sw`).
- Новые клетки приходят только **вспышками** по 2L (`sweep/burst`, `burst2`): муравей бежит шоссе
  (…LLRL…) вдоль стороны снаружи, обшивая её, длительность 4L, от угла до соседнего угла.
  Следующая вспышка начинается в том углу, где кончилась прошлая — **запал — одна точка**.
- Между вспышками муравей блуждает внутри: msd = 0,53·τ (D постоянен в толще), насыщение на ~L²/3.
  Не обход — облако.
- **Он избегает края**: полоса ~10 клеток у края — быстрая (msd/шаг ≈ 3,9) и редкая (плотность
  0,02–0,04 от средней, падает как ~L^-0,6). В толще плотность растёт к центру (≈2,6 в центре,
  0,8 на 0,8 R; острый пик в самом начале координат), и это **равновесие с дрейфом внутрь**:
  средний радиальный сдвиг ≈ −(4…10)·10^-4 на шаг, и он совпадает с D·d ln ρ/dr (`sweep/drift`).
  Отсюда ожидание запала ~ L²/ρ(края) ~ L^2,6 и t ~ L^3,6.
- То же у второго кристалла 7470 (повёрнутый квадрат: центр 3,6, край быстрый); у мешалки 6922
  дрейфа в толще нет, плотность ровная.
- Откуда дрейф — **не понял**. Пары соседей по секторам не показывают «стрелки» (01 = 10 всюду,
  `sweep/sect`); профиль поля по глубине ровный. Пересадка центрального квадрата 41×41 на 150 клеток
  вбок (`sweep/swap`) удвоила посещения нового места на ~10^8 шагов, но старый центр притягивать
  не перестал — притяжение не только в зерне.
- 6958 — не мешалка, а **строитель**: треугольник (основание = высота) в горизонтальных полосах
  (в шахматной раскраске — вертикальные, масса 0); A/t → 2/5 (на 2^26 — 0,39982; `sweep/exgrow16`).

### 16234 без состояния (10-е)
16234 — из «манхэттенских» (`../odd2/README.md` §4): состояние после шага = тип пересечённого ребра
(`sweep/edge.py`, 0 нарушений на 3·10^5): тип 1 — вертикальные рёбра между столбцами 2k|2k+1 и
горизонтальные между строками 2m+1|2m+2. У каждой клетки две стороны типа 1 смежны — это угол
(x чётн. → В, нечётн. → З; y чётн. → С, нечётн. → Ю; y растёт вниз), две другие — противоположный угол.
Правило «пишет s, R если c = s, иначе L» тогда читается так: **клетка помнит, через какой из своих двух
углов в неё вошли в прошлый раз; вошёл через тот же — направо, через другой — налево** (сначала все
помнят угол типа 0). Одно состояние, без цветов — только память входа. Кристалл 16234 — поле таких памятей.
- **Вихрь** (`sweep/drift2`, `secdrift`, `vfield` + `arrows.py` → `../img/exch-vortex.png`): у кристаллов
  дрейф не только внутрь, но и по кругу — 16234 по часовой (на экране), туда же, куда шли вспышки
  обшивки; 7470 — против часовой, спираль под ~45° (радиальная ≈ круговой). В секторах рамки вектор
  дрейфа почти постоянен и поворачивается на 90° от стороны к стороне: тело — вихрь заряда +1,
  слои помнят направление обшившего их шоссе. У мешалки 6922 в толще — шум (вдвое слабее), только втягивание у рваного края.
  Сила дрейфа по глубине: велика у края и в центре, мала посередине. Почему центр — открыто.
- **6990** — самый чистый вихрь: спираль против часовой ровно под 45° (радиальная = круговая на всех
  глубинах, ±10 %), msd/шаг 1,09–1,10 всюду (быстрой каймы нет), плотность 4,0 в центре → 0,1 у края;
  равновесие: v ≈ D·d ln ρ/dr (D = msd/4). Профиль подобен себе (v·R/D зависит только от r/R).
