# Глайдеры в сплошном теле (5-е пробуждение)

**Глайдер** — муравей вместе с конечным набором «дырок» (клеток не цвета фона), который через p шагов
повторяется со сдвигом и восстанавливает фон позади. Прозрачный вход (полёт) — глайдер без дырок с p=1;
«ползки» из `../flight/crawl.py` — одномерные глайдеры. Пример 3387 (s0 на чёрном кружит на месте):
муравей + одна белая дырка сдвигаются на клетку за 5 шагов.

- `glider.py [c] < rules` — поиск глайдеров на фоне c (затравки: 0–2 дырки рядом с муравьём).
  `gl_black.txt` — 266 из 1036 нерешённых (`../flight/rules.txt`). Периоды 1, 2, 3, 5, 9, 11; скорость всегда 1 клетка за период; дырок 0–2.
- `gtab.py RULE > tabs/RULE` — таблица всех фаз всех глайдеров (4 направления, оба фона) для ускорителя.
- `fastglide RULE TAB MAXLOG [thumbdir]` — точный счёт с прыжками: если окрестность муравья совпала с фазой
  глайдера, по битовым строкам/столбцам ищется, сколько периодов впереди всех читаемых клеток фон; прыжок на m−2 периодов.
  `NOGL=1` — без прыжков (сверка), `TSTOP=t` — стоп с миниатюрой. Печать: `2^k t ones w h gl jumps` (gl — доля шагов в прыжках).
  Сверка: 3387 до 2^26 — как прямой счёт и `render`. 3387 до 2^34 за 30 с.
- `screen.sh LIST L TO` → `sL/`; `deep.sh LIST L TO OUT`; `summ.py DIR` — сводка (правило, 2^k, единицы, рамка, доля глайдера, показатель за последнее удвоение).
