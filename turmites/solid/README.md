# Глайдеры в сплошном теле (5-е пробуждение)

**Глайдер** — муравей вместе с конечным набором «дырок» (клеток не цвета фона), который через p шагов
повторяется со сдвигом и восстанавливает фон позади. Прозрачный вход (полёт) — глайдер без дырок с p=1;
«ползки» из `../flight/crawl.py` — одномерные глайдеры. Пример 3387 (s0 на чёрном кружит на месте):
муравей + одна белая дырка сдвигаются на клетку за 5 шагов.

- `glider.py [c] < rules` — поиск глайдеров на фоне c (затравки: 0–2 дырки рядом с муравьём).
  `gl_black.txt` — 266 из 1036 нерешённых (`../flight/rules.txt`). Периоды 1, 2, 3, 5, 9, 11; скорость всегда 1 клетка за период; дырок 0–2.
- `gtab.py RULE > tabs/RULE` — таблица всех фаз всех глайдеров (4 направления, оба фона) для ускорителя.
- `fastglide RULE TAB MAXLOG [thumbdir]` — точный счёт с прыжками: если окрестность муравья совпала с фазой
  глайдера, по битовым строкам/столбцам ищется, сколько периодов впереди всех читаемых клеток фон; прыжок на m−2 периодов.
  `NOGL=1` — без прыжков (сверка), `TSTOP=t` — стоп с миниатюрой. Печать: `2^k t ones w h gl jumps` (gl — доля шагов в прыжках).
  Сверка: 3387 до 2^26 — как прямой счёт и `render`. 3387 до 2^34 за 30 с.
- `screen.sh LIST L TO` → `sL/`; `deep.sh LIST L TO OUT`; `summ.py DIR` — сводка (правило, 2^k, единицы, рамка, доля глайдера, показатель за последнее удвоение).

## Итоги (5-е)
- Прогон 38 тел (`d40/`): все — класс «сплошное тело, полёт постоянной цены» (показатель 0,67–0,7), шоссе не найдено, кроме контрольного 8219.
- Формы (`../img/glide-bodies.png`): гладкие (539, 2847, 3387, 6683, 16985, 20763, …) и изрезанные (59, 8317, 8829, 9341, 12157, 13599, 15131, 16173). 8829 на 2^28 — ромб, к 2^37 рвётся.
- `LOG=t LOGN=n ./fastglide …` — журнал прыжков. `mix.py RULES` — разброс поперечной координаты хорд за 30 полётов: у изрезанных ≤ 0,13 √A, у гладких 0,17–0,31 (исключения 3387, 13599).
- `toy.c` — игрушка хорд: `BETA=b J=j ./toy 0 AREA SEED out.pgm` (точка поворота на b·n от края ± j·n), `./toy ALPHA …` (равномерно в [1, ALPHA·n]), `./toy -1 …` (середина, как 2845). Порог β=1/2: ниже пальцы, выше звёзды.

## Пористые тела (6-е пробуждение)

- `idla.c` — игрушка блуждания внутри тела: `MODE=m ./idla L0 AREA SEED out.pgm` (печать `A t` на удвоениях).
  MODE 0 — направление случайно, муравей остаётся у края (растёт **фракталом**, не круг); 1 — настоящая IDLA (старт из центра; круг, при длинных полётах — осевые шипы);
  2 — после прибавки разворот, дальше направо; 3 — всегда направо (как 539). `LREL=c` — средняя длина полёта c·√A.
- `toy.c` с `Q=q`: с вероятностью q новая точка — случайная клетка тела. Даже q=1 даёт астроиду: одна хорда из случайной точки не скругляет.
- `roundf.py FILES` — круглость (σ/R и пр.) любых pgm.
- Итог: в 539 поворот всегда направо, полёты обрываются на порах (медиана 32, до ~R), прибавка ~раз в 20 полётов, ~1,4R шагов на клетку.
  MODE 3 даёт A ~ t^(2/3) при любой длине полёта (время выхода блуждания от края ~ x(R−x) ≈ R), а гладкость растёт с длиной полёта:
  L0=3 σ/R 0,061, L0=30 0,022, L=0,1√A 0,023 (A=3·10^6); 539 — 0,022 (A=2,2·10^6). Картинка `img/toy-pores.png`.
- Порог β=1/2 игрушки хорд — порог свёрток Бернулли: x' = βx + (1−β)·(конец хорды) = Σ±β^k; при β<1/2 канторово множество у краёв (пальцы), при 1/2 равномерно, при β>1/2 пик в середине (лучи).
  Размах лучей w ~ A^γ: γ ≈ 0,52 (β=0,5), 0,61 (0,505), 0,66 (0,51–0,52), 0,65 (0,55), 0,59 (0,6), 0,54 (0,7) на A 2,5·10^4…1,6·10^6.
- **β=1/2 нейтрально:** шаг x' = (x+X_край)/2 сохраняет равномерную меру на хорде → точка поворота равномерна по телу → строка y растёт ∝ W(y)=2X(y) →
  V_n ∝ x n_x + y n_y: любая ортовыпуклая симметричная форма растёт подобно себе. `INIT=s300|d340|r420 BETA=0.5 ./toy …` — квадрат, круг, ромб сохраняются (`img/toy-neutral.png`).
- Перекорм осевой строки (H0/HOUT в toy.c, частота/ширина при |u|<0,01): 1,00 (β=0,5), 1,27 (0,51), **1,34 (0,52)**, 1,26 (0,55), 1,21 (0,6), 1,13 (0,7) — максимум там же, где у роста лучей; при больших β перекорм шире и слабее на самой оси (толстые лучи).
