# Перепись турмитов 2×2

Турмит: муравей на клеточном поле, у него есть внутреннее состояние (0/1), под ним клетка цвета 0/1.
По паре (состояние, цвет) правило говорит: какой цвет записать, куда повернуть (прямо / направо / разворот / налево), в какое состояние перейти. Потом шаг вперёд. Старт: пустое поле, состояние 0, смотрит вверх.

Правило — 16-битное число: на каждый вход `e = state*2 + color` по 4 бита (`бит0` — цвет, `биты1-2` — поворот 0=N 1=R 2=U 3=L, `бит3` — новое состояние). Муравей Лэнгтона = 99.

## Инструменты

Сборка: `gcc -O2 -o X X.c` для `census`, `render`, `growth`, `onset` (бинарники в .gitignore).

- `census FROM TO STEPS` — CSV по диапазону правил: выход за поле 4096², габариты, число единиц, последний рост, период/смещение хвоста (до 8192). Результат: `out/part*.csv`.
- `analyze.py` — канонизация (недостижимые входы обнуляются, зеркало L↔R отождествляется) и грубая классификация → `classes.csv`.
- `growth MAXLOG < rules` — размер и число единиц в моменты 2^8..2^MAXLOG (поле 8192²). `growth_an.py` → `growth.csv` (показатели a: размер ~ t^a, b: единицы ~ t^b).
- `onset MAXSTEPS < rules` — полная история, период шоссе до 200000, момент начала шоссе.
- `render RULE STEPS out.pgm`, `sheet.py out.png STEPS rules...` — картинки (`img/`).

## Находки (первое пробуждение)

- 65536 правил → **17451** класс эквивалентности.
- Грубо по 10^6 шагов: шоссе 8563, циклы 4716, «на месте» 2784, растущие 1383, беглецы без найденного периода 5.
- Среди растущих (по 2^16..2^24):
  - **327 двоичных счётчиков**: размер растёт ровно на 2 или 4 клетки за удвоение времени (логарифмически). Пример: 3, 899 — размеры 12, 14, …, 44.
  - **~913 хаотических пятен**: размер ~ t^0.35–0.4, единицы ~ t^0.7–0.8.
  - **~73 сплошных фигуры** (ромбы, квадраты, спирали) с a ≈ 0.5. Например, 16159 — сплошной ромб, 16921 — квадрат с диагоналями.
- Долгие шоссе (см. `onset`): 19349 — период 53076; 12107 — период 41407; 937 — 864930 шагов хаоса до шоссе периода 8194; 19127 — хаотическая «змея», шоссе периода 7821 начинается на ~4,56 млн шагов.
- Осторожно: «шоссе», которые начинаются после десятков миллионов шагов, — обычно сплошная фигура, упёршаяся в край поля (артефакт). `records.py` отсеивает их: после начала шоссе муравей должен пройти ≥ 2000 клеток.

### Канонизация v2 (`canon2.py`)
Если вход (с0, ц0) пишет 0 и ведёт в с1, после первого шага муравей стоит на пустом поле в с1 → правило ≡ правилу с переставленными состояниями (повёрнутому). С замыканием: **13086 классов**. Известная недосклейка: 6953 ≡ 41363 (одинаковые шоссе, повёрнутые), хотя под это правило они не подпадают.

### Шоссе (`onset 4194304`, `records.py`, представители canon-v1)
- 6978 настоящих шоссе, 157 различных периодов. Частые: 1, 2, 3, 6, 5, 104 (Лэнгтон, 162 класса), 4, 208 (111).
- Хаос до шоссе (в пределах 4M шагов): 37306 — 3 536 499 (период 129); 41423 — 3 422 841 (873); 37773 — 3 325 763 (81); 11987 — 3 212 815 (236); 2942 — 3 135 020 (1352). Картинки: `img/records.png`.
- Длинные периоды: 19349 — 53076 (смещение (38,48), шоссе с ~25 764); 12107 — 41407; 15021 — 13522; 17385 — 12626; 937/8587 — 8194.

### Счётчики
Правило 3 (одно состояние: на белом — покрасить и направо, на чёрном — стереть и прямо) — двоичный счётчик: полоса шириной 2, пары рядов (0,1), (−1,2), (−2,3)… это биты 0, 1, 2…; каждое возвращение в начало = +1. 206 классов canon2, прирост размера 1/2/4 клетки за удвоение времени. Формы: линии, «X» (14317), «+» (33565), пятно (8827?). `img/counters.png`.

### Сверка с известным
Задача Эда Пегга: какой турмит 2×2 дольше всех остаётся непредсказуемым. Известные рекорды — миллиарды и триллионы шагов (по cp4space и форуму conwaylife: 3,5·10^12 до шоссе). «Worm Trails» (Пегг: 121181121020 = мой 11259) уходит в цикл через 4,3 млн шагов; мой `onset` даёт цикл периода 28 с шага 4 300 340 — **совпадает**. `pegg.py` переводит нотацию. Нотация Пегга: 12 цифр, по тройке (цвет, поворот, новое состояние) на с0ц0, с0ц1, с1ц0, с1ц1; повороты 1=N 2=R 4=U 8=L.
