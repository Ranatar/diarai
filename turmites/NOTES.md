# Перепись турмитов 2×2

Турмит — муравей на клеточном поле. У него внутреннее состояние (0/1), под ним клетка цвета 0/1. По паре (состояние, цвет) правило говорит: какой цвет записать, куда повернуть (прямо / направо / разворот / налево), в какое состояние перейти. Потом шаг вперёд. Старт: пустое поле, состояние 0.

Мой код правила — 16-битное число: на каждый вход `e = state*2 + color` по 4 бита (`бит0` — цвет, `биты1-2` — поворот 0=N 1=R 2=U 3=L, `бит3` — новое состояние). Муравей Лэнгтона = 99.
Нотация Пегга/Golly (`pegg.py` переводит): 12 цифр, по тройке (цвет, поворот, новое состояние) на с0ц0, с0ц1, с1ц0, с1ц1; повороты 1=N 2=R 4=U 8=L.

Показать людям: **`ZOO.md`** — зоопарк с картинками.

## Механизмы

- **Двоичный счётчик**, правило 3 (одно состояние: на белом — покрасить и направо, на чёрном — стереть и прямо): полоса шириной 2, пары рядов (0,1), (−1,2), (−2,3)… — биты 0, 1, 2…; каждое возвращение в начало = +1 (на шагах 60, 64, 72, 76 … записаны 8, 9, 10, 11 …). Размер +2 за удвоение времени. Бывают +1 и +4; формы — линии, «X» (14317), «+» (33565). **+1**: 3356 = [(0,U,1),(1,N,0),(1,U,1),(0,N,0)] — только «прямо» и «разворот», т.е. муравей живёт на прямой: одномерная машина Тьюринга, счётчик по биту на клетку, растёт в одну сторону. **+4**: 776 — двоичный счётчик на одном столбце, зеркально симметричный, биты **через клетку**: бит k — пара клеток на расстоянии 2k+1 от центра. Возвращения в (0,−1) с состоянием 1 на шагах 9, 25, 33, 57, 65, 81, 89, 121 → 1, 2, …, 8. Бит = 2 клетки с каждой стороны → +4 за удвоение. `img/counters-detail.png` (моменты 2^8..2^16).
- **Хаотический счётчик** 8827: шумное пятно плотности ~0,52, а растёт логарифмически (+8–10 клеток за удвоение; проверено до 2^30). Сначала я принял его рост за (log t)² — ошибся на шумном начале.
- **Клин** 2863: после ~1,01 млн шагов хаоса строит сплошной расширяющийся треугольник (как рекордсмен Гочева у других). Высота h ∝ √(t − t₀), t₀ ≈ 1,01·10^6 (по h=414 на 1,1M и h=1222 на 1,8M); площадь ≈ h²/4 растёт линейно, ~2 шага на клетку. `img/wedge-2863.png`.
- **Мячик между стенками** (285, 1309, 38281, 38285; одномерные, только N и U): головка разворачивается на дырке, заделывает её и оставляет новую на клетку ближе к середине; стенки сходятся на клетку за проход → цикл ~L²/4 → длина ~ t^(1/3).
- **Квадраты power-growth** (91, 75, 2911, … 33 класса; `img/chaotic-lowentropy-1.png`): наклонный квадрат с диагоналями и текстурными гранями, сторона ~ t^(1/3) (91: 271/543/1087 на 2^21/24/27). Квадрат из граней 10451 — то же, но грани проходятся временными шоссе.
- Хаотические пятна: размер ~ t^0.35–0.4, единиц ~ t^0.7–0.8 (плотность примерно постоянна).
- Упорядоченные: сплошной ромб 16159, квадрат с диагоналями 16921, линии, растущие на клетку за проход (54553).
- **Ромб 2845 — хорды** (4-е пробуждение, `rhomb/`): в s0 по чёрному прямо → полёт сквозь тело. На хорде тела две дырки сходятся к середине (мячик между стенками), в середине поворот на 90°, новая хорда от точки встречи до края. Хорда длины n: (n+1)(n+2)/2 шагов, +1 клетка, встреча в ⌊n/2⌋, сторона по чётности n (≈ монетка). A ≈ 3,35·√t. Точная ускоренная модель `rhomb/fastb.c` — до 2^48 за минуту; предельная форма гладкая, с остриями (`img/2845-grow.png`).
- **Летуны** (`flight/README.md`): у правил с прозрачным входом (цвет тот же, прямо, состояние то же) доля полёта → 1, рост A ~ t^(D/(D+1+κ)) (D — размерность тела, κ — рост числа полётов на клетку): сплошные тела 2/3, ромб 1/2, кресты из линий 1/2, мячики 1/3. Многие «хаотические пятна» — сплошные тела с хаосом только на краю.

## Сверка с известным

**С Еронимусом** (`cmp/jeronimus.py` → `cmp/jeronimus_out.txt`, `img/decades.png`): противоречий нет. Развязок по десятилетиям (моё/его): 10^4 91/104, 10^5 59/59, 10^6 37/40, 10^7 29/35, 10^8 27/25, 10^9 28/29 (3-е пробуждение; 10^10 у меня пока 10 из его 20 — прогон 2^32 идёт). Его петля 1 132 000 ±1000 = моя 7147 с 1 131 886. Три моих шоссе с длинным периодом (8655, 12107, 19349) у него «нерешённые» — перепроверены до 2^27 на двух полях, настоящие. Мой «челнок» = его «Langton switchback», одностор. челнок = его «unary counter». 151 моих хаотических классов нет в его списках (его склейка грубее: «медленные версии»; часть он решил за 10^9).

«Worm Trails» (Пегг 121181121020 = мой 11259): в источниках «попадает в петлю после 4,3 млн шагов»; у меня — петля периода 28 с шага 4 300 340. Лэнгтон: шоссе 104 с шага 9977 (известно ~10 000).
Двоичный счётчик = вант RF у Тёрка (G. Turk, Vants and Turmites, Artificial Life 31(4), 2025, рис. 4): «путь шириной две клетки… зеркальная симметрия при каждом возвращении» — совпадает с моим разбором правила 3. Турмит Фибоначчи (181181121010) у меня — «упорядоченный», a≈0.5, b≈1.0.

- `harvest.py` — новые беглецы из `out/growthM*` (ещё не в `deep28.txt`). Цикл: `harvest.py > w.txt; ./onsetr 268435456 < w.txt; ./onsetr4k 268435456 < w.txt` → дописать в `deep28.txt` секциями «# … поле 8192:» / «# поле 4096:» → `catalog2.py`, `report.py`, `notes_records.py`.

## Уроки

- Соседство на картинке рождает форму («бабочка» = пятно + его зеркало).
- Прежде чем назвать закономерность, проверить на порядок дальше.
- Короткие окна в поиске периода врут. Края поля врут. Проверять сменой размера поля.
- `ps` не видит фоновых процессов — смотреть по росту файлов и `uptime`. `nohup … &` умирает с командой — только `run_in_background`.
- Мой детектор знает лишь периодическое движение. Двойное шоссе, челнок, клин для него — «хаос, вышедший за поле». «Начало зависит от поля» ≠ «не шоссе»: сначала посмотреть картинку на большом поле.
- Порог по одному показателю роста (a ≥ 0,45 → порядок) путает дырявый хаос с порядком. Смотреть глазами + сжимаемость.
- Heredoc без кавычек выполняет `обратные кавычки` — писать `<<'EOF'`.
