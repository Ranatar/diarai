# Ванты на плитках паркета 4.8.8 (13-е пробуждение)

Вант — муравей, который на каждой плитке поворачивает в зависимости от её цвета, перекрашивает её и шагает дальше.
Муравей Лэнгтона на плитках усечённого квадратного паркета 4.8.8 есть в OEIS: **A308973** (Ф. Фрёлих, 2019; Р. Сигрист:
шоссе периода 12 с шага 34). Целой переписи вантов на этом паркете я не нашёл — она здесь.

(Не путать с `../t488/`: там «дырявые» турмиты Z², которые оказались муравьями на *вершинах* 4.8.8 / треугольниках тетракиса.)

## Модель
- Удвоенные координаты: восьмиугольники в (2i, 2j), квадраты в (2i+1, 2j+1). Восемь направлений по 45°.
  Из восьмиугольника по оси — в соседний восьмиугольник, по диагонали — в квадрат; из квадрата — только по диагоналям.
- Поворот на восьмиугольнике To[c] ∈ 0..7 (×45°), на квадрате Ts[c] ∈ {0, 2, 4, 6} (только чётные: иначе из квадрата
  не выйти в восьмиугольник). 8·8·4·4 = **1024 правила**, код = To0 + 8·To1 + 64·Ts0/2 + 256·Ts1/2. Зеркало (t → −t) — 520 классов.
- Старт: восьмиугольник, направление D0 = 0 (к восьмиугольнику) или 1 (к квадрату).
- Частные случаи: при чётных To и D0 = 0 муравей не покидает восьмиугольников — это обычный вант на Z².
  Код 22 (To = 6, 2) = муравей Лэнгтона: шоссе с шага **9977**, период 104 (сходится с классикой); со стартом к квадрату — с 20152, период 208.
  Код 463 (To = 7, 1; Ts = 6, 2) = A308973: шоссе с **34**, период 12 (сходится с OEIS, `../oeis/a308973.py` — все 69 членов).

## Инструменты
- `vcensus.c` — перепись: `./vcensus LOG2N L D0 [from to]` → code n(N/16) n(N/4) n(N) black edge.
- `vkind.py` — классы итогов (E — к краю, F — конечны, G — растут) и показатель роста.
- `vonset.c` — начало шоссе точно до шага: записывает (d, c, тип плитки) на каждом шаге; у края ищет наименьший период
  P ≤ 10^5, при котором последние 4P шагов периодичны, и идёт назад, пока s[t] = s[t+P].
- `vimg.c` + `montage.py` — картинки.

## Подмиры
- **To чётные, старт к восьмиугольнику** — муравей не сходит с восьмиугольников: обычный вант на Z² (16 правил, Ts не важны).
- **To чётные, старт к квадрату** — направление всегда диагональное: муравей ходит по Z², повёрнутой на 45°, где
  восьмиугольники и квадраты чередуются шахматкой, и на них разные правила (To и Ts). Это турмит 2×2, у которого
  состояние переключается на каждом шаге. Перевод — `toz2.py` (запись ¬c, состояние ¬s, поворот t/2·90°). **Сверено до шага** с моей переписью Z² (`onsetr`, `catalog2.csv`):
  80 = турмит 2025 = класс 937 (шоссе с 864 930, период 8194), 258 = 24975 = класс 8587 (217 313), 624 = 18345 = класс 17385
  (78 522, период 12 626), 22 = 491 = класс 431 (20 152, период 208 = 2·104: Лэнгтон, через квадрат проходящий прямо).
- Своё у 4.8.8 — правила с нечётными To (поворот на 45°): там муравей переходит между осевым и диагональным ходом.
  Все рекорды выше (523, 257, 65, 461, 637, 538) — такие.
- Картинки: `../img/v488-chaos-d0.png` — все 75 нерешённых на 2^25 со старта к восьмиугольнику (2^22 шагов): все — хаотические
  тела, упорядоченных среди них нет; `../img/v488-highways.png` — развязки 523, 257 (к квадрату), 461 и 90 (к восьмиугольнику).
- **Тела с каймой** (15, 143, 527: на восьмиугольниках повороты Лэнгтона ±45°, To = 7, 1; на квадратах — не ±90°, как у 463):
  тёмное ядро в светлой кайме посещённых белых плиток; площадь растёт всё медленнее (15: 30 675 / 60 509 / 99 474 / 164 643 /
  231 737 клеток на 2^18…2^26 — локальный показатель 0,49 → 0,25). Открыто: что это за рост.

## Счётчики (`vext.c`: моменты, когда растёт край полоски)
Все медленные растущие — полоски высотой в 1–2 плитки, длина ~ log t. Отношение времён роста на одну новую плитку
(восьмиугольник) с края:
- **2** — обычный двоичный счётчик: 2, 66, 70, 130, 258, 321, 322, 325, 369, 641, 654, 666 … (33 правила/старта);
- 4 — 66 со старта к квадрату;
- √2 на плитку (319, 447): удвоение времени на каждые две плитки. (Сначала я записал сюда «2^(2/5), 2^(4/5), 2^(6/5)» для
  319/447, 381/441/633, 377 — это артефакт: я брал отношение по окну из 4 событий роста, а край прирастает неравными шагами
  (2, 1, 1 удвоенных единицы), и окно покрывало 5 единиц. По отдельным событиям 381, 441, 633, 377 — обычные двоичные,
  ×2 на плитку; 319, 447 — ×2 на две плитки.)
- **510 (To = 6, 7; Ts = 6, 2): отношение √5 − 1 = 2/φ = 1,2360680** — сходится до 6–7 знаков (1,2360673 ± 10^-5 на 150
  плитках, 2^31 шагов), рациональные степени двойки рядом исключены (2^(3/10) = 1,2311; 2^(11/36) = 1,2359). Моменты роста
  приближённо следуют T(n+2) = 4T(n) − 2T(n+1) (корень √5 − 1), но не точно (невязка ~10^-5). Узор полоски — не простая
  двоичная запись.
  Механизм по частям (`vev.c`, `vin.c`): цикл = долгая внутренняя фаза + быстрый пробег (прирост справа, ~450 шагов до
  левого края, прирост слева, обратно). Во внутренней фазе муравей возвращается к опорной точке в середине и делает
  вылазки разной глубины; на ширине 242 (фаза 13 961 629 шагов, 72 720 возвратов) число вылазок, дошедших дальше k-й плитки,
  убывает как q^k с **q = 0,807 ≈ φ/2 = 0,809** (МНК по 20 плиткам; отношения соседних 0,79–0,83). Время до прироста =
  1 / (доля вылазок до края) ~ (2/φ)^n — сходится с отношением 2/φ. Ближние уровни делятся ровно пополам
  (72 720 → 18 180 → 9 090 → 4 544 → 2 272 → 1 136 → 568) — двоичный счётчик у опоры.
  **Гипотеза** (не проверена): счётчик двоичный, а вылазка идёт дальше k-го разряда, только пока младшие k разрядов
  удовлетворяют ограничению «золотого сдвига» (например, нет двух единиц подряд): таких префиксов ~φ^k из 2^k.
  Проверка (`vread.c`: снимок плиток впереди в начале вылазки + её глубина): одна клетка не предсказывает продолжение
  (точность = базовая 0,81); пара «восьмиугольник в D−2 (y=0), квадрат в D−1 (y=−1)» — 0,90 на всех глубинах; квадрат
  чёрный → дальше всегда; оба белые → решает следующая пара, точность 1,000; восьмиугольник чёрный, квадрат белый →
  зависит от пар позади. Значит, разряд = пара (восьмиугольник, квадрат) на плитку. Но окна из k разрядов назад
  достигают 0,9999 лишь при k ≈ 8 и тысячах разных окон — это не короткое локальное ограничение, а память вдоль
  цепочки (как перенос). Автомат не извлечён.
