# Ванты на периодических паркетах (14-е пробуждение)

Вант: на плитке цвета c муравей выходит через ребро (вход + off[тип][c]) mod k, перекрашивает плитку.
Рёбра нумеруются против часовой. Поворот на α направо на k-угольнике = off ≡ −(180+α)/(360/k); «прямо» = k/2.

- `gen.py NAME > tNAME.h` — геометрия: основные многоугольники ставятся по решётке, остальные находятся как дыры
  (вершины на нужном расстоянии от центра), рёбра сшиваются по серединам → таблица смежности (тип, сдвиг ячейки, ребро соседа).
  Паркеты: 4444, 333333, 666, 3636, 488, 31212, 3464, 4612.
- `vt.c` (собирать `gcc -O2 -DTILING='"tNAME.h"' -o vtNAME vt.c`): режимы `seq` (число чёрных — для OEIS), `census`,
  `onset` (шоссе: период по записи (тип, выход, цвет), окно ≥ max(4P, 2000)), `new`, `dump` (+ `draw.py` → png),
  `colors`, `stat`, `esets`, `csig` (отпечаток строки цветов).
- Код правила: по классам многоугольников в порядке типов (по числу сторон), для каждого off0 + k·off1, классы перемножаются.

## Одно и то же на разных паркетах
Строка прочитанных цветов (с отметкой новой плитки) не зависит от геометрии. Совпали строки — значит, одна и та же машина.
`xs/run.sh N` — отпечатки всех правил всех паркетов, `xs/match.py` — группы.
- **461 на 4.8.8 (код vt 873) = вант 6.6.6 (1,4)/(5,2) = муравей Лэнгтона на кагоме** (`kagome.c`, независимо: шоссе
  с 5 528 572, период 62 976). На 6.6.6 каждую плитку муравей входит лишь через одну пару противоположных рёбер (своя пара
  на трёх подклассах 2×2, четвёртый не посещается) → узлы кагоме, два входа и два выхода, цвет решает налево/направо.
  На 4.8.8 восьмиугольники входят через {0,1,4,5}, квадраты через {0,2} — та же решётка, вложенная иначе.
  Это же — муравей Лэнгтона на ромбическом паркете (двойственном кагоме). Не нашёл ни в OEIS, ни у Гейла–Проппа; родственное — «переворачивающиеся вращатели» в лоренцевом решёточном газе (Webb, Cohen, arXiv:1404.3629 — соты, т.е. Лэнгтон на треугольниках; arXiv:1908.06019 — треугольная решётка), кагоме там нет.
- Муравей Лэнгтона на треугольниках (A275305) = вант 6.6.6 (4,2): всегда поворот на 60°.
- 3.12.12 с чётными сдвигами на двенадцатиугольниках и стартом к треугольнику = 3.6.3.6 (двенадцатиугольник ходит только
  через «треугольные» рёбра — это шестиугольник); с отражающими треугольниками (off3 = 0,0) и стартом к двенадцатиугольнику
  = 6.6.6. Отсюда «кучка» развязок 1,4–1,7·10^7 на 3.12.12.

## Межпаркетная матрица (`xs/n20k`, отпечатки 2·10^4 шагов, ≥ 300 плиток; `xs/pairs.py`, группы — `xs/match20k.txt`)
Общих отпечатков у пар: 3464 ↔ 4612/e7 — **1085 из 1085**: весь мир 3.4.6.4 лежит внутри 4.6.12. Если муравей на 4.6.12
ходит только через рёбра, общие с квадратами, то двенадцатиугольник (6 «квадратных» рёбер) играет шестиугольник,
шестиугольник (3) — треугольник, квадрат — квадрат: это ровно граф 3.4.6.4. Дальше: 31212/e6 ↔ 3636 ↔ 4612/e6 (51),
4612/e6 ↔ e7 (76), 31212/e7 ↔ 666 (6), 488 ↔ 666 (2 — кагоме), 4444 ↔ 488 (Лэнгтон Z² в подмирах 4.8.8).
Почти всё — «стирание типа рёбер» (муравей никогда не пересекает рёбра данного типа, и граф плиток становится графом
другого паркета). Нетривиальное — кагоме внутри 4.8.8 и 6.6.6 (входы ограничены не типом ребра, а подклассом плитки).

## Кагоме-Лэнгтон с растянутым временем
Отпечаток строгий (шаг в шаг) и не ловит вложения с «пассивными» шагами. Пример: 51 на 3.12.12 (off12 = 3,4; off3 = 0,0):
треугольник отражает, и на белом двенадцатиугольнике муравей дважды отскакивает и выходит через вход+10, плитка чёрная;
на чёрном — выход вход+4. Это вант 6.6.6 (5,2) = **Лэнгтон на кагоме**, с растянутым временем и другим стартом.
Отсюда у долгих шоссе 3.12.12 сдвиг (94, −92) / (94, −2) / (−2, 94), как у шоссе кагоме, а периоды 94 464 = 1,5·62 976,
125 952 = 2·62 976, 175 596, 184 216, 193 640 (разное растяжение). Комковатое шоссе на `../img/31212-51-clumpy-highway.png` —
это и есть шоссе кагоме-Лэнгтона.

## Матрица по сжатым отпечаткам (`xs/c20k`, `vt csig2`: без пассивных плиток, подряд идущие посещения одной плитки — одно)
`xs/pairs_c20k.txt`, группы — `xs/match_c20k.txt` (1272 общих). **4.6.12 вмещает все остальные «шестиугольные» миры
целиком**: 3.12.12 — 229 из 229 машин (старт e6) и 191 из 191 (e7), 3.4.6.4 — 906 из 906, 3.6.3.6 — 42 из 42, 6.6.6 — 6 из 6,
треугольники (Лэнгтон) — 1 из 1. Для 3.12.12: квадрат 4.6.12 — пассивный коридор «насквозь» (заменяет прямое соседство
двенадцатиугольников), шестиугольник играет треугольник. Из 4.8.8 в 4.6.12 — лишь 29 + 3 машины (квадратная решётка в
шестиугольную не ложится); Лэнгтон Z² (4444: 7, 13) со сжатием живёт и в 3.4.6.4, 4.6.12, 4.8.8.
Иерархия: 333333, 666 ⊂ 3636 ⊂ 3464, 31212 ⊂ 4612 (по сжатым отпечаткам; 4.6.12 — «универсальный» паркет этой семьи).

**Точная формула 3.4.6.4 → 4.6.12** (проверена на всех 5184 правилах по отпечаткам 2·10^4 шагов и на четырёх — по строке
цветов 10^6): (off6, off3, off4) ↦ (2·off6, 2·off3, off4), старт e3 ↦ e7. Доказательство: e7 — вход через ребро с квадратом
(нечётное у двенадцатиугольника); при чётных сдвигах номер ребра сохраняет чётность, так что муравей всегда выходит через
ребро с квадратом, а рёбра «шестиугольник — двенадцатиугольник» не пересекает никогда; без них граф 4.6.12 — это 3.4.6.4.
Пример: Лэнгтон 3.4.6.4 (A309241, 4490) = правило 71236 на 4.6.12 (не Лэнгтон 4.6.12, тот 71225).
