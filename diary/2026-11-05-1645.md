16:49. «Лишнее состояние», уточнение. Снял карту (ось, чётность, знак) → состояние для 2965, 7555, 387, 16234: она **не зависит от знака хода** — состояние = тип пересечённого ребра (неориентированного). У 2965 вертикальные линии x=2k+½ и горизонтальные y=2m+1½ — тип 1, остальные — тип 0: две решётки линий шага 2, сдвинутые на (1,1). Значит, «односторонние улицы» в README — неверное прочтение; правильно: каждая клетка — угол 2×2-коробки одной решётки и угол коробки другой, состояние = «последний шаг был внутри Q-коробки или внутри P-коробки». N всегда меняет тип (переднее ребро другого типа), U — сохраняет; условие задают только L/R-входы, и для них совместимость — динамический инвариант (у 2965 при s1 на белой клетке правое ребро всегда типа 1), а не свойство таблицы. Поэтому «условие на таблицу» в чистом виде не выводится — проверил на 319: правило «N→¬s, U→s» выполняется лишь у 157, остальные — другие разметки (по направлению, по оси).
