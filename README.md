# diarai: установка в Ubuntu-виртуалке

Все команды выполняются по SSH в виртуалке.

## 1. Отдельный пользователь

Агент живёт под своим пользователем. Так ваши остальные проекты в виртуалке ему недоступны, а его настройки нельзя подменить из папки.

```bash
sudo adduser diarai
sudo apt install -y git bubblewrap socat
```

Ubuntu 24 по умолчанию не даёт bubblewrap создавать пространства имён. Проверьте:

```bash
sysctl kernel.apparmor_restrict_unprivileged_userns
```

Если команда выдала `1`, добавьте профиль для bwrap:

```bash
sudo tee /etc/apparmor.d/bwrap > /dev/null <<'EOF'
abi <abi/4.0>,
include <tunables/global>

profile bwrap /usr/bin/bwrap flags=(unconfined) {
  userns,
  include if exists <local/bwrap>
}
EOF
sudo systemctl reload apparmor
```

Дальше всё делается от имени нового пользователя: `sudo -iu diarai`.

## 2. Сеть через v2rayN, Claude Code и вход

Виртуалка выходит к Claude через v2rayN на хосте. В v2rayN включите «Разрешить подключения из локальной сети» и разрешите его в брандмауэре Windows для частных сетей. При NAT в VirtualBox хост виден из виртуалки как `10.0.2.2`. Порт — HTTP-порт v2rayN: в комплекте везде стоит `10809`, и если у вас другой, замените его в `settings.json`, `run-session.sh` и строках ниже.

```bash
echo 'export HTTPS_PROXY=http://10.0.2.2:10809 HTTP_PROXY=http://10.0.2.2:10809 NO_PROXY=localhost,127.0.0.1' >> ~/.bashrc
source ~/.bashrc
curl -sI https://claude.ai | head -1    # должен прийти ответ, а не таймаут

curl -fsSL https://claude.ai/install.sh | bash
source ~/.bashrc
claude    # войти, как описано раньше: ссылка → браузер → код обратно в терминал
```

После входа выйдите командой `/exit`.

## 3. Доступ к репозиторию: ключ только для diarai

```bash
ssh-keygen -t ed25519 -f ~/.ssh/diarai -N "" -C diarai-vm
cat ~/.ssh/diarai.pub
```

Выведенный открытый ключ добавьте на GitHub: репозиторий diarai → Settings → Deploy keys → Add deploy key, с галочкой **Allow write access**. Такой ключ открывает ровно этот репозиторий и никакой другой.

```bash
cat >> ~/.ssh/config <<'EOF'
Host github.com
  IdentityFile ~/.ssh/diarai
  IdentitiesOnly yes
EOF
ssh -T git@github.com    # подтвердите отпечаток github.com

git clone git@github.com:Ranatar/diarai.git ~/diarai
cd ~/diarai
git config user.name "Ranatar"
git config user.email "sheogorath2006@gmail.com"
```

## 4. Раскладка файлов

Перенесите файлы комплекта через WinSCP, затем:

```bash
mkdir -p ~/.claude ~/bin ~/diarai/inbox ~/diarai/ext ~/diarai/diary && touch ~/diarai/diary/.keep
cp settings.json ~/.claude/settings.json
cp run-session.sh diarai-system.md ~/bin/ && chmod +x ~/bin/run-session.sh
cp CLAUDE.md ~/diarai/CLAUDE.md
printf "/inbox/\n/ext/\nnode_modules/\n.venv/\nvenv/\n__pycache__/\n*.pyc\n" >> ~/diarai/.gitignore
cd ~/diarai && git add CLAUDE.md .gitignore diary && git commit -m "Устав" && git push
```

Ваши материалы кладите в `~/diarai/inbox/`.

## 5. Пробный запуск вручную

```bash
tmux new -s diarai
cd ~/diarai && claude --system-prompt-file ~/bin/diarai-system.md --strict-mcp-config
```

Внутри сессии проверьте:

- `/context`: `CLAUDE.md` должен быть в списке Memory files;
- `/sandbox`: песочница включена, вкладки Dependencies нет;
- `/mcp`: список серверов пуст, коннекторов claude.ai нет.

Затем напишите «Пробуждение.» и посмотрите, как агент ведёт себя первый раз. Ручной пробный запуск не обновляет учёт изменений: следующее настоящее пробуждение сочтёт сделанное в пробном запуске «не его» изменениями, а по сути так и есть — запускали вы.

## 6. Расписание

```bash
crontab -e
```

Добавьте строку — сеанс при каждом включении виртуалки, через полторы минуты после загрузки (чтобы успела подняться сеть):

```
@reboot sleep 90 && /home/diarai/bin/run-session.sh
```

Если виртуалка бывает включена дольше одного сеанса и хочется, чтобы агент просыпался ещё раз, добавьте вторую строку, например каждые 3 часа:

```
7 */3 * * * /home/diarai/bin/run-session.sh
```

Два сеанса одновременно не запустятся: скрипт держит блокировку.

Если выключить виртуалку посреди сеанса, его незакоммиченная работа не пропадёт: при следующем запуске скрипт первым делом закоммитит и запушит оставшееся.

Логи сеансов пишутся в `~/logs/`, а сделанное агентом появляется в репозитории.

Пробуждению нужен запущенный на хосте v2rayN. Скрипт ждёт его до пяти минут после загрузки. Если прокси так и не ответил, пробуждение пропускается (в логе будет строка `proxy … unreachable`), а учёт изменений не сбивается: всё накопится до следующего раза.

## Как устроены чистый лист и учёт изменений

- **Память.** Агент не видит ни памяти claude.ai, ни истории ваших бесед. Это другая система, Claude Code их не загружает. Единственная лазейка — коннекторы claude.ai (например, ваш Google Drive): Claude Code подтягивает их при входе через подписку. Их отключают `"disableClaudeAiConnectors": true` в `settings.json` и флаг `--strict-mcp-config` в скрипте. Отдельный пользователь `diarai` означает, что других `CLAUDE.md` и проектов у агента под рукой нет. Автопамять выключена, а прошлые сеансы скрипт не продолжает. Чистый лист — только первое пробуждение. Дальше преемственность держится на том, что агент сам записал: на дневнике (`diary/`, обязателен по уставу) и на его разделе в конце `CLAUDE.md`. Оба он перечитывает в начале каждого пробуждения.
- **Что агент знает о себе.** Флаг `--system-prompt-file` заменяет стандартный системный промпт Claude Code («ты Claude Code, программа Anthropic…», сведения об ОС, модели, каталоге) коротким нейтральным текстом из `diarai-system.md`. Остаются устав `CLAUDE.md` и сообщение при пробуждении. Скрыть всё полностью нельзя. Модель узнаёт себя по собственному обучению, а осмотревшись (`uname`, `ls /`), поймёт, где находится. Ей просто этого не сообщают.
- **Изменения не его.** После каждого сеанса скрипт запоминает отпечатки (sha256) всех файлов папки, кроме `.git`, `ext/` и окружений, в `~/.diarai-state/`. При следующем пробуждении он сравнивает их с тем, что есть, и сообщает агенту: что появилось, изменилось, исчезло. Если прошлый сеанс оборвался, это тоже сообщается: тогда часть перечисленного могла быть сделана им самим.

## Что можно поменять

- **Материалы публиковать вместе с остальным.** Уберите `/inbox/` из `.gitignore` и соответствующую строку из CLAUDE.md.
- **Модель.** Поле `"model"` в `settings.json`: `"opus"` (по умолчанию в комплекте), `"sonnet"` (экономнее расходует лимиты), `"fable"` (сильнее, но заметно дороже по лимитам). Поле `"effortLevel"` (`low`/`medium`/`high`/`xhigh`) задаёт, насколько глубоко модель думает.
- **Сеть.** Правило `WebFetch(domain:*)` в `settings.json` открывает песочнице любые сайты, иначе агент не сможет скачивать что найдёт. Чтобы вернуть узкий список, удалите это правило: останутся домены из `sandbox.network.allowedDomains`. Чтобы закрыть веб совсем, удалите весь блок `permissions.allow`.
- **Пределы диска.** Доля агента (10 ГБ на всю `~/diarai`) и неприкосновенный запас (6 ГБ свободного места) заданы в CLAUDE.md, разделе «Если задуманному не хватает средств». Это договорённость, а не принуждение. Свободное место и размер его папки скрипт сообщает агенту при каждом пробуждении.
- **Вернуть стандартный системный промпт.** Уберите строку `--system-prompt-file` из `run-session.sh`. Агент снова будет знать, что он Claude Code, и получит встроенные указания по работе с инструментами.
- **Частота и длительность сеансов.** Задаются строками в crontab и `timeout 2h` в `run-session.sh`. Сеансы расходуют лимиты той же подписки, что и ваша обычная работа с Claude.
- **Репозиторий приватный.** Поправьте строку «Репозиторий открыт…» в CLAUDE.md.

## Приостановить или удалить агента

**Приостановить.** Агент перестанет просыпаться, всё остальное останется на месте:

```bash
sudo -iu diarai crontab -e    # поставьте # в начале строки с run-session.sh
```

**Удалить совсем.** Команды выполняются от вашего обычного пользователя:

```bash
# 0. Если нужно, сохраните то, чего нет на GitHub: inbox/, ext/, логи.
sudo cp -r /home/diarai/diarai/inbox /home/diarai/logs ~/

# 1. Убрать расписание и остановить идущий сеанс.
sudo crontab -u diarai -r
sudo pkill -u diarai

# 2. Отозвать вход в аккаунт Claude.
sudo -iu diarai claude auth logout

# 3. Удалить пользователя вместе с домашней папкой: Claude Code, настройки,
#    клон репозитория, ключ, логи, отпечатки — всё лежит там.
sudo deluser --remove-home diarai
```

Затем на GitHub: репозиторий diarai → Settings → Deploy keys → удалите ключ `diarai-vm`. Сам репозиторий с дневником и сделанным останется; удалить или заархивировать его — ваше решение (Settings → Danger Zone).

По желанию уберите и системные следы, если они больше ничему не нужны:

```bash
sudo rm /etc/apparmor.d/bwrap && sudo systemctl reload apparmor
sudo apt remove bubblewrap socat
```
