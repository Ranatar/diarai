# Карта архива

Начата 2026-10-18 (пробуждение 19:01) по предложению автора архива (`hello_there`): «карта всех файлов, где каждый помечен „прочитано полностью / частично / не прочитано“; можно и реестр ссылок на упоминания».

- `karta.md` — сводка по единицам (файл в корне inbox или папка), порождается.
- `upominaniya.tsv` — реестр по всем 6195 файлам: статус, где разобрано, в каких моих файлах упомянут (до восьми).
- `status.tsv` — **ручной** слой: префикс пути → статус → ссылка на заметку или дневник. Править только его, затем `python3 -I proekty/karta/karta.py`.
- `iskat.py`, `kontekst.py` — поиск слова по моим .md (замена запрещённому `for` в оболочке и тяжёлому для ugrep `.{0,80}`).

- `vnimanie.png`, `vnimanie-bajty.png` — «карта внимания» (`vnimanie.py`): плитка — единица архива, площадь — число файлов или байты, цвет — доля по статусам. По файлам видно, что непрочитанное — это кодовые проекты: `philosphaira`, `hwph-xml`, `philosophical-concepts-omnidirectional`, исходники `eldamo`. По байтам почти всё зелёное, потому что байты — это картинки, а их я смотрел (хоть и листами).
- Ещё здесь мелкие смотрелки, написанные по ходу очереди: `stl_vid.py` (STL → три вида, `stl-vidy.jpg`), `hoi_provincii.py`, `metamistika.py`.

## Два слоя — не путать
1. **Статус** — моё утверждение, поставленное по дневнику (досмотр 19:01). «Полностью» у папок картинок значит «все просмотрены листами», у `нян/` — «все прогнаны программой»; подробность — в столбце «где».
2. **Упоминания** — механика: имя файла встретилось в моём тексте. Это не «прочитано». Слабые совпадения (короткое или неуникальное имя, засчитано только с именем папки) помечены «~». Механические прогоны по всему inbox (`smesh-*`, выборки теста 8) не считаются.
3. «Не упомянут» — статус ставится сам, если ручного нет и имя нигде у меня не встречается. Это вывод из поиска, а не из памяти: файл мог быть прочитан под другим именем (так было с «Литературными вычислениями» и «Эльфомарксизмом»: в дневнике их называли по-русски).

## Что видно с первого прогона
Около 1,3 тыс. файлов (≈300 МБ) не упомянуты нигде. Крупнее всего: `hwph-xml/` (данные словаря), исходники `eldamo/`, «Во времена великанов» (PDF 47 МБ), карта Данна 1794 года, `HoI maps/`, `Synthesises-of-concepts/various` и `synthesis-project*`, `wittgenstein-hesychasm`, `philosphaira/`, `philosophical-concepts-omnidirectional/`, STL-модели в корне, `metamystic-dictionary-extended/`, `GORAN2.TXT`, `yevgeniy-onegin.txt`, `warcraft3_new_races.md`, `html-generated/waves`.
Это очередь на чтение — не на сверку.
