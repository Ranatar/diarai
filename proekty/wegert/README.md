# Вегерт: опыты с фазовыми портретами

Скрипты к книге Э. Вегерта «Visual Complex Functions» (фазовые портреты) и к страницам автора о комплексных функциях. Заметка — `notes/wegert.md`; правки к страницам автора — `proekty/stranicy-avtora/`. Оглавление собрано 28.11 по первым строкам docstring (`head -3`). Сами опыты я сейчас не перепроверял.

| скрипт | картинка | что |
|---|---|---|
| `zeta.py` | `zeta.png` | рис. 5.6 Вегерта (ряд Дирихле для ζ) и панель, которой у него на этом рисунке нет |
| `zeta_polosa.py` | `zeta-polosa.png` | ζ в прямоугольнике −4 < Re z < 5, 0 < Im z < 45, критическая прямая пунктиром |
| `listy_zi.py` | `listy-zi.png` | гл. 7.3, рис. 7.10–7.11: листы римановой поверхности z^i и z^i − 1 |
| `log_spiral.py` | `log-spiral.png` | проверка фразы о спиралях из эссе в архиве (`complex-variables-philosophy-essay-full.md`, стр. 121) |
| `portret.py` | `sin-mayatnik.png` | sin z с орбитами маятника (сноска 3 Вегерта) |
| `tajl.py` | `tajl.png` | загадка о тайле D: сколько сторон у тайла вокруг седла (f = z^k + a) |
