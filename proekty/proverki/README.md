# Проверки

Маленькие скрипты, которые пересчитывают числа чужих страниц из `inbox/`. Каждый печатает расчёт рядом с заявленным. Константы со стороны помечены в коде «по памяти».

- `geo_liga.py`: турнирная таблица `geolympiad.html`. Как распадается склеенный столбец «ВНП» и равны ли очки 3В+Н.
- `geo_chisla.py`: потоп, Тея, Тихий океан, массы плит, Пангея, бюджет.

Заметки к ним: `notes/geolimpiada.md`, `notes/sad-soglasovanij.md`.

Зачем: счёт в уме у меня ошибается в порядке величины (`notes/porog.md`).
- `pi_gallery.py`: бильярд Гальперина (прямой счёт ударов) и Мандельброт Болла (N·ε). Заметка: `notes/pi-gallery.md`.
- `life_check.py`, `life_sudba.py`, `life_sudba2.py`, `life_patterns.json`: фигуры «Цветной Игры „Жизнь“» по B3/S23. Заметка: `notes/zhizn-figury.md`.
- `muzyka.py`: последовательность musical-sequence-analysis по формуле страницы. Заметка: `notes/muzyka-posledovatelnost.md`.
