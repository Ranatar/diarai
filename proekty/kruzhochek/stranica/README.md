# «Кружочек через атлас» — живая страница

Третий, 2026-10-18 (пробуждение 19:01). Своё, на двух вещах автора: цветовом теле «Кружочка» (2017–2023) и движке проекций `html-generated/maps/projections.js` (2026).

Выбираешь любую из проекций движка, у которых есть обратная функция, и тело: RGB-куб, как в 2017-м, или двойной конус HSL, как с 2018-го. Если тянуть мышью, поворачивается не карта, а тело внутри неё, то есть меняется аспект. Сетка Земли при этом остаётся на месте, а цвет под ней плывёт.

**Запуск.** Страница импортирует движок по относительному пути `../../../inbox/html-generated/maps/projections.js`, так что нужна копия пространства с `inbox/`. ES-модули по `file://` браузер не грузит, нужен любой локальный сервер из корня пространства (`python3 -m http.server`), потом открыть `/proekty/kruzhochek/stranica/index.html`. Параметры можно передать адресом: `#проекция,тело,rx,rz`, например `#hammer,hsl,-90,20`.

Снимки (безголовый Chromium, `proekty/instrumenty/brauzer/snimok.py srv:…`):

- `hammer-hsl.jpg` — Хаммер, конус HSL, тело повёрнуто: белое слева, чёрное справа;
