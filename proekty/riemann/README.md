# «Neue Zählung»: явная формула Римана 1859 года

Мемуар — `ext/riemann/Zeta.tex` (расшифровка Д. Р. Уилкинса, по Gesammelte Werke 1892, с. 145–153). В конце Риман пишет: «Bei einer etwaigen neuen Zählung würde es interessant sein, den Einfluss der einzelnen in dem Ausdrucke für die Dichtigkeit der Primzahlen enthaltenen periodischen Glieder zu verfolgen». Здесь я это и делаю: беру его формулу

f(x) = Li(x) − Σ_α [Li(x^(½+αi)) + Li(x^(½−αi))] + ∫ₓ^∞ dx/((x²−1) x log x) + log ξ(0)

(строки 334–339) с K первыми нулями и смотрю, как с ростом K из неё проступает лестница f(x) = F(x) + ½F(x^½) + ⅓F(x^⅓) + … (строки 217–219; F — число простых, на скачке — полусумма). Сейчас эту f чаще пишут J(x) или Π₀(x).

## Предсказания (записаны 21.10, 06:51, до первого счёта)
1. Li(x^ρ) нельзя считать как li от главного значения x^ρ: у log(x^ρ) берётся главная ветвь, и для ρ = ½ + it при t·log x > π значение уйдёт на другой лист. Верно Ei(ρ·log x). Риман оговаривает это сам (строки 320–330: интеграл от 0 до x «um 2πi verschiedene Werthe, je nachdem…»). Предсказываю: «наивная» сумма разойдётся с лестницей на величины порядка π на член, «правильная» сойдётся.
2. С K = 50 нулями ступеньки у простых до x ≈ 60 будут видны глазом, с K = 0 будет гладкая кривая Li(x) − log 2.
3. Константа. У Римана стоит log ξ(0), где ξ — его функция от t (s = ½ + ti, строки 141–143), так что ξ(0) — значение при s = ½. Сегодняшняя запись формулы (по памяти) даёт −log 2 ≈ −0.693. Предсказываю, что числа будут разными (ξ(t=0) не ½) и что верна −log 2. Различие маленькое, увижу ли я его численно, — не знаю.

## Результаты (21.10, ~07:00; скрипт `yavnaya.py`, нули — `mpmath.zetazero`, кэш `ext/riemann/nuli.json`)

**1. Ветвь — подтвердилось, и сильнее, чем я думал.** Вывод `yavnaya.py tochki 0 10 50 200`, x = 10.5 (точно f = 5.3333):

| K | через Ei(ρ log x) | «наивно», li(главное x^ρ) |
|---|---|---|
| 0 | 5.6890 | 5.6890 |
| 10 | 5.2771 | −23.94 |
| 50 | 5.3941 | −140.16 |
| 200 | 5.3395 | −576.95 |

Наивная сумма не просто ошибается на «порядка π на член», как я предсказывал. Она уходит линейно: при x = 10.5 примерно на −2.9 за каждый нуль, при x = 97.5 — на −5.98 ((−1167.74 − 28.89)/200; поправка по проверке: сначала я обобщил «−2.9» на все x). С ростом K она не сходится вовсе. Правильная сходится: при K = 200 ошибка в пяти точках 0.006, −0.003, 0.045, 0.018, 0.012. Риман знал, что здесь всё решает выбор пути (строки 320–330). Это та же тема, что в атласе: точка ветвления, принятая за обычную, ломает всё.

**2. Лестница — подтвердилось.** `lestnica.png`: K = 0 — гладкая кривая. K = 10 — волны, которые уже держатся за ступеньки. K = 50 — почти лестница, с мелкими колебаниями Гиббса у скачков. Видны и мелкие ступеньки у степеней простых (4, 8, 9, 16, 25, 27, 32, 49): это ½F(x^½), ⅓F(x^⅓) и т. д., Риман их и учитывает в f.

**3. Константа — не решено.** log ξ(t=0) = −0.69892, −log 2 = −0.69315, разница 0.0058. Средняя ошибка по 90 точкам x = n + 0.5, n = 10…99: с −log 2 — −0.0022 (K = 100) и +0.0016 (K = 200); с log ξ(t=0) — −0.0080 и −0.0042. Стандартная ошибка среднего 0.0069 и 0.0045, да и точки не независимы. Перевес у −log 2, но в пределах шума. Что у Римана здесь описка или иное прочтение ξ(0), я по памяти утверждать не буду: это надо смотреть у Эдвардса («Riemann's Zeta Function», 1974), а его у меня нет.
Поиск (21.10) прямого ответа не дал. Пересказчик поиска сам «посчитал», что ξ(0) = ½. Но это значение функции ½s(s−1)π^(−s/2)Γ(s/2)ζ(s) при **s = 0**, а у Римана ξ(0) — при **t = 0**, то есть при s = ½ (≈ 0.4971). Та же путаница, из-за которой вопрос и возник, только сделанная уверенно. Открыто: проверить по Эдвардсу, гл. 1. Подсказка в самом мемуаре (заметил проверяющий): строка 145 даёт ξ(t) = ½ − (tt + ¼)∫₁^∞ ψ(x) x^(−3/4) cos(½t log x) dx, то есть ξ(0) = ½ − ¼∫ψ x^(−3/4) dx < ½. Значит, у Римана ξ(0) — это именно значение при t = 0, ≈ 0.4971, а не ½.
