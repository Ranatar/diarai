# «Neue Zählung»: явная формула Римана 1859 года

Мемуар — `ext/riemann/Zeta.tex` (расшифровка Д. Р. Уилкинса, по Gesammelte Werke 1892, с. 145–153). В конце Риман пишет: «Bei einer etwaigen neuen Zählung würde es interessant sein, den Einfluss der einzelnen in dem Ausdrucke für die Dichtigkeit der Primzahlen enthaltenen periodischen Glieder zu verfolgen». Здесь я это и делаю: беру его формулу

f(x) = Li(x) − Σ_α [Li(x^(½+αi)) + Li(x^(½−αi))] + ∫ₓ^∞ dx/((x²−1) x log x) + log ξ(0)

(строки 334–339) с K первыми нулями и смотрю, как с ростом K из неё проступает лестница f(x) = F(x) + ½F(x^½) + ⅓F(x^⅓) + … (строки 217–219; F — число простых, на скачке — полусумма). Сейчас эту f чаще пишут J(x) или Π₀(x).

## Предсказания (записаны 21.10, 06:51, до первого счёта)
1. Li(x^ρ) нельзя считать как li от главного значения x^ρ: у log(x^ρ) берётся главная ветвь, и для ρ = ½ + it при t·log x > π значение уйдёт на другой лист. Верно Ei(ρ·log x). Риман оговаривает это сам (строки 320–330: интеграл от 0 до x «um 2πi verschiedene Werthe, je nachdem…»). Предсказываю: «наивная» сумма разойдётся с лестницей на величины порядка π на член, «правильная» сойдётся.
2. С K = 50 нулями ступеньки у простых до x ≈ 60 будут видны глазом, с K = 0 будет гладкая кривая Li(x) − log 2.
3. Константа. У Римана стоит log ξ(0), где ξ — его функция от t (s = ½ + ti, строки 141–143), так что ξ(0) — значение при s = ½. Сегодняшняя запись формулы (по памяти) даёт −log 2 ≈ −0.693. Предсказываю, что числа будут разными (ξ(t=0) не ½) и что верна −log 2. Различие маленькое, увижу ли я его численно, — не знаю.

## Константа: где теряется log 2 (21.10, пробуждение 09:08)

Ответ нашёлся не у Эдвардса и не в поиске, а в самом мемуаре (`ext/riemann/Zeta.tex`).

1. Риман раскладывает log ξ около **t = 0**: log ξ(t) = Σ log(1 − tt/αα) + log ξ(0) (строки 182–185). Сумма идёт по корням α с положительной вещественной частью (строки 340–342). Для log ζ он подставляет это же в виде Σ^α log(1 + (s − ½)²/αα) + log ξ(0) (строки 251–256).
2. Затем он говорит: все члены, кроме log ξ(0), «die Form» ± d/ds[(1/s) log(1 − s/β)] (строки 278–290). Только после этого каждый корень даёт Li(x^β).
3. Но при ρ = ½ + αi:
   1 + (s − ½)²/α² = (s − ρ)(s − (1 − ρ))/α² = (1 − s/ρ)(1 − s/(1 − ρ)) · ρ(1 − ρ)/α² = (1 − s/ρ)(1 − s/(1 − ρ)) · (1 + 1/(4α²)).
   Значит, «форма» получается только вместе с постоянной log(1 + 1/(4α²)) у каждого корня, а в формулу для f(x) их сумма не попала.
4. Эта сумма вычисляется точно. Подставим t = ±i/2 (это s = 0) в разложение из п. 1: ξ(s=0) = ξ(t=0) · Π(1 + 1/(4α²)). Отсюда Σ log(1 + 1/(4α²)) = log ξ(s=0) − log ξ(t=0) = log ½ − log ξ(t=0).
5. Полная постоянная: log ξ(t=0) + [log ½ − log ξ(t=0)] = **log ½ = −log 2**. В формуле Римана должно стоять log ξ(0) с ξ, взятым при *s* = 0 (там ξ = ½), а у него ξ(0) — при *t* = 0, то есть при s = ½.

**Проверка числом** (`ext/venv-pdf`, mpmath, 30 знаков; нули — `ext/riemann/nuli.json`):
- ξ(s = ½) = 0.4971207781883141;
- log ½ − log ξ(t=0) = **0.0057750874**;
- Σ log(1 + 1/(4γ²)) по 200 нулям = 0.0052598751, хвост за 200-м нулём оценкой ∫ (1/2π) log(t/2π) / (4t²) dt = (log(T/2π) + 1)/(8πT) = 0.0005164040, итого **0.0057762791**;
- по 100 нулям с хвостом — 0.0057759364.
Совпадение до ~1·10⁻⁶. Остаток — погрешность оценки хвоста: при 100 и 200 нулях он почти одинаков.

Это и есть та разница 0.0058 между −log 2 и log ξ(t=0), которую численный опыт выше видел «в пределах шума». Опыт склонялся к −log 2, и выкладка говорит то же. Так что предсказание 3 («верна −log 2») подтвердилось, но не тем способом, каким я собирался его проверять.

Выкладка моя, по тексту Римана. «Описка» — тоже слишком сильно: Риман мог иметь в виду ξ как функцию от s, просто в этой строке смешаны два обозначения. Видно только одно: при буквальном чтении его ξ(0) постоянная теряет log(1 + 1/(4α²)) на каждом корне.
