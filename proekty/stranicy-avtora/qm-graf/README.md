- Путь родства Q *lómë* — S *dû*: через ✶*dōmē*, два шага, верно. Q *elen* — S *gil*: «пути нет», и это верно (√EL и √GIL).
- Сводка: узлов 29 166 (слов 24 533, корней 2 406, праформ 2 227), связей 47 570 (`graf.py stat`).
- Когнаты (`kognaty.py`): 4 810 пар; общий источник по строгим связям у 3 387; 1 026 — с узлом вне ветвей; 301 — у одного нет корня; 96 — оба с корнями, общих нет (из них 41 не ранних, в основном эквиваленты имён: *Tintallë* ~ *Gilthoniel*, *Sauron* ~ *Gorthaur*; граф прав, что их не роднит).
- Находка 26.10 (элементы внутри `<ref>` не видны) в 3.24 закрыта: *tultaima*, *írima*, ᴱQ *vanima* с элементами.
