# Экспорт Claude.ai → читаемый Markdown

Для `inbox/json/` (письмо автора от 26.10.2026). В трёх zip лежит экспорт Claude.ai:
`conversations.json` (два файла, 200 и 102 МБ) и `memories/<uuid>.json` (3 МБ).

## Как развернуть

```sh
mkdir -p ext/json-raw
unzip -o -q inbox/json/conversations-000.zip -d ext/json-raw/c0
unzip -o -q inbox/json/conversations-001.zip -d ext/json-raw/c1
unzip -o -q inbox/json/memories-000.zip -d ext/json-raw/m0
python3 -I proekty/json-export/razvernut.py ext/json-out \
    ext/json-raw/c0/conversations.json ext/json-raw/c1/conversations.json \
    --memories ext/json-raw/m0/memories/*.json
python3 -I proekty/json-export/temy.py ext/json-out
```

Нужен только Python 3, без библиотек. Памяти на это уходит около 1,5–2 ГБ: первый файл читается целиком. Выход занимает около 63 МБ, что внутри — см. `ext/json-out/README.md`, его пишет сам скрипт.

## Что выяснилось о самих данных

- **Кодировка в порядке.** Кириллица и греческий записаны как `\u0444`, `\u03a6`: так JSON по умолчанию экранирует всё, что не ASCII. Mojibake (кириллицы, прочитанной как latin-1) нет, это проверял `pustye.py`. После `json.load` текст обычный.
- **Записи о разговорах:** 2043. У 1467 нет названия, и все сообщения в них пустые: ни текста, ни блоков, ни файлов. Сохранились только даты и uuid, их список — в `pustye.tsv`. Больше всего таких до марта 2026, потом их резко меньше (`pustota.py`). Скорее всего, экспорт не отдаёт содержимое старых или удалённых чатов. Содержимое есть у 576 разговоров.
- **Внутри сообщения** лежат блоки `text`, `thinking`, `tool_use`, `tool_result`, `image`, `document`, `token_budget`, `injected_prompt_block`. Приложенные файлы в экспорт не попали, остались только их имена. Исключение — `attachments` с `extracted_content`: в них текст есть.
- **Ветвление.** У каждого сообщения есть `parent_message_uuid`. При правке или перегенерации у одного родителя появляется несколько детей. Разговоров с ветвлением много: в первом файле 636 из 2000. Встречается и вырожденный случай: десятки пустых «человеческих» сообщений, подвешенных к корню.
- **Память.** Это общий текст `conversations_memory` и 92 файла `memory_files` (`/areas/…`, `/topics/…`, `profile.md`, `preferences.md`). У каждого файла есть frontmatter: name, description, aliases. Ссылки вида `[s:<16 hex>]` с uuid разговоров не сопоставляются: ни напрямую, ни через md5/sha1/sha256 от uuid (`istochniki.py`, 0 из 17). Поэтому темы связываю с разговорами по словам (`temy.py`).

## Инструменты

| файл | что делает |
|---|---|
| `razvernut.py` | главный: разговоры → `.md`, файлы из вызовов → `.faily/`, память → `pamyat/`, указатели |
| `temy.py` | `temy.md`: область памяти → разговоры, где встречаются её имя и псевдонимы |
| `kvenya_ukazatel.py` | `kvenya.md`: разговоры, где много эльфийских слов (по лексикону Quettamin) |
| `struktura.py` | обзор ключей и типов блоков |
| `pustye.py` | пустые сообщения по месяцам, поиск mojibake |
| `pustota.py` | пустые разговоры по месяцам (по `index.tsv`) |
| `instrumenty_vyzovy.py` | какие инструменты вызывались и с какими полями; ветвление |
| `istochniki.py` | попытка связать метки `[s:…]` с uuid |
